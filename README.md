# Plantão no Pix

Landing page de antecipação de plantões para médicos.

Publicada via GitHub Pages: https://iomeswesley.github.io/plantao-no-pix/

- `index.html`: página completa (HTML + CSS + JS, sem build)
- `assets/`: fotos e ilustração
- Simulador: taxa de 0,1666% ao dia (exibida como 0,16%); período padrão = dias até o dia 30 do mês seguinte
- Botões "Continuar" e "Solicitar antecipação" abrem o WhatsApp +55 47 99763-2683 com valor e período
